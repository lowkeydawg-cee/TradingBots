Risk Bot

An async Python bot for automated risk governance, data logging and disciplined execution on a mock crash-game feed.

What it does
  • Runs a strict state machine with circuit breakers, loss limits and a persistent kill latch.
  • Logs every event to SQLite and a hash-chained journal that can be replayed deterministically.
  • Never predicts outcomes, never uses martingale recovery and never applies machine learning to random data.
It runs on your machine, not here

This is a long-running program, not a website. This page is only an overview. To run it:

pip install -r requirements.txt && python -m riskbot --scenario normal -v

Code, docs and the companion pairs-trading bot: github.com/lowkeydawg-cee/TradingBots
